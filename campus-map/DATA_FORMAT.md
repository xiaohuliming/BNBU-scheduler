# campus-map/map_data.json format

Consumed by `campus-map/index.html` (no build step). `.md` files are blocked by
`block_sensitive_project_files`, so this doc is repo-only and never served.

```jsonc
{
  "image": {
    "src": "map.webp",      // hand-drawn map file, relative to /campus-map/
    "width": 4000,          // informational; naturalWidth wins at runtime
    "height": 2800
  },
  "credit": "手绘地图 © …", // attribution line, bottom-right corner

  "calibration": {
    // Optional manual override. When null it is derived from the gps points
    // (mean haversine-meters / pixel-distance over all point pairs).
    "metersPerPixel": null,
    // >=3 non-collinear points map image pixels -> WGS-84. Enables:
    //  - derived building lat/lng (Amap/Baidu jump links)
    //  - the "locate me" button (inverse affine)
    // Pick unambiguous spots (gates, building corners) and read lat/lng
    // from OSM (WGS-84 — do NOT paste GCJ-02 coords from Amap).
    "gps": [
      { "x": 1234, "y": 567, "lat": 22.3811, "lng": 113.5401 }
    ]
  },

  "buildings": [
    {
      "id": "T29",               // unique, used in deep links (#b=T29)
      "name": "T29 教学楼",
      "aliases": ["理工楼", "science building"],  // extra search keys
      "category": "teaching",    // teaching|admin|dorm|dining|sports|library|gate|service|landmark
      "x": 2100, "y": 900,       // marker position, image pixels
      "nodes": ["n12", "n13"],   // entrance node ids; omit -> nearest node
      "lat": null, "lng": null,  // optional explicit WGS-84 (else derived via affine)
      "desc": "一句话介绍，显示在信息卡"
    }
  ],

  // Walking-path graph, image-pixel coordinates.
  "nodes": { "n1": [1000, 800], "n2": [1200, 820] },
  // undirected; weight = euclidean px distance × metersPerPixel.
  // Optional 3rd element = explicit real-world meters, needed where the
  // hand-drawn map is not to scale (IAS / sports-park zone is drawn ~2.5x
  // compressed vs the core campus, so px distances there lie).
  "edges": [ ["n1", "n2"], ["n2", "n9", 600] ]
}
```

Routing: multi-entrance Dijkstra (virtual source/target over `nodes` of each
building, straight-line cost building→entrance). No path / empty graph falls
back to a straight line marked 按直线估算. Distances render only when
metersPerPixel is known; walking time assumes 72 m/min.

This file is GENERATED by root-level `build_campus_map.py` (cp the official
map jpg to /tmp/srcdata/ first). Building lat/lng come from OSM (© OpenStreetMap
contributors, ODbL). The script also renders a QA overlay (nodes/edges/markers
drawn on the map) to /tmp/campus_map_qa.png — eyeball it after every edit.
To annotate a NEW map image: overlay a labeled coordinate grid on the image
(PIL, see the script's QA section for the pattern), read positions off zoomed
crops, and edit the script's B / N / E / ENTR tables.
