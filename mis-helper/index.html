Interface

先认识控制台

Install

安装插件

Chrome 商店之外的扩展需要通过开发者模式加载。整个过程只需完成一次。

01

下载并解压

点击页面上的下载按钮，解压 bnbu-mis-course-helper-extension.zip，保留解压后的完整文件夹。

02

打开扩展管理页

在 Chrome 地址栏输入下面的地址并回车。

chrome://extensions/
03

加载已解压的扩展程序

开启右上角的“开发者模式”，点击“加载已解压的扩展程序”，选择刚才解压出的 bnbu-mis-course-helper-extension 文件夹。

04

打开 MIS 并刷新

加减课阶段打开 BNBU MIS 加减课首页，无需先手动搜课。普通选课使用 普通选课入口。新旧 MIS 域名均支持，更新插件后请刷新页面。

05

固定到工具栏

点击 Chrome 右上角的扩展程序按钮，将“抢课脚本”固定到工具栏，之后就能随时打开控制台。

Configure

填写配置

配置会保存在浏览器扩展存储中。运行前请再次核对课程代码、班号和时间。

01

输入目标课程

每行填写课程代码，例如 ENG3143，或用 ENG3143 | 1001 指定班号。加课模式会自动逐门搜索；同一课程填写多个班号时视为按顺序选择的备选，只加其中一班。

02

设置运行时间

开始时间留空表示立即运行，结束时间留空表示持续运行，直到选课成功或手动停止。

03

设置检查与重试

检查间隔默认 0.5 秒，指一次请求完成后再发起下一次，不会叠加并发请求。提交超时保留 10 秒；加课结果不明确时只查询已注册课程，仍无法确认则暂停，不盲目重复提交。

允许加入轮候仅普通选课模式使用。加课模式不会申请轮候或执行退课。
自动确认选课自动加课时保持开启；关闭后只搜索名额，不提交。
接口直提并确认自动加课时保持开启，使用学校同源表单并核对已注册课程。
桌面通知成功、停止或需要注意时显示 Chrome 通知。
Run

开始运行

确认 MIS 已登录并保持页面打开。加课模式只在一个标签页运行，准备好课程代码即可开始，不需要手动搜索。

01

保存或开始

“仅保存配置”不会启动监测。“开始监测”会保存当前配置并立即进入等待或检查状态。

02

观察当前状态

控制台和 MIS 页面右下角会显示正在搜索的课程。满额或冲突时继续检查其他目标，不会点击禁用按钮。手动刷新后会恢复配置，并先核对上一笔未确认的加课。

03

核对最终结果

加课模式在全部目标出现在“已注册课程”中或到达结束时间后停止。已注册其他班号的课程需要手动处理，脚本不会退课换班。普通选课仍按原逻辑在首次成功或轮候成功后停止。

!

运行期间不要关闭 MIS 页面

必须保持页面打开、登录有效且电脑不休眠。服务器拥堵会延长检查和提交时间，插件无法加速学校服务器。不要同时启用同类油猴脚本，否则可能重复提交。

FAQ

常见问题

一直显示“正在连接 MIS 页面”怎么办？

请使用 v2.5.0 或更新版本，登录后打开普通选课模块 /mis/student/es/ 或加减课首页 /mis/student/as/home.do。安装或更新后需要刷新页面；登录过期时请重新登录。

可以关闭 MIS 页面或让电脑休眠吗？

不可以。插件依赖已打开的 MIS 页面和有效登录状态。关闭页面、退出账号或让电脑休眠都会中断监测。

为什么服务器拥堵时还是会等待？

0.5 秒是请求完成后的检查间隔，服务器处理请求仍需要时间。加课提交结果不明确时，插件会先查询已注册课程；仍无法确认会暂停，避免重复提交。

为什么出现 Add 也可能不会提交？

脚本只处理目标课程和班号的可用 Add。按钮被学校禁用、存在 Full 或 Clash、已注册其他班号、需要确认类别学分提醒或页面结构变化时，都不会强行提交。

提示加课结果未确认，怎样恢复？

先停止监测并到 MIS 核对已注册课程。停止不能撤回已经发出的请求。确认结果后点击插件中的“已核对结果，解除暂停”，再重新开始；已加上的课程会自动跳过。

可以和油猴版本同时使用吗？

不建议。两个工具可能同时执行并造成重复操作，请只保留一个版本运行。
