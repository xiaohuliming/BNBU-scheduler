Toolbox / Campus Printing
Set up campus printing in two clicks

校园打印一键配置

自动把 UIC 图书馆的共享打印机 (172.16.244.66 / DP, Toshiba e-STUDIO 457) 加进你的电脑。

三种安装方式 · 任选其一

三种方式装好的是同一台打印机，挑一种做完就行，不用三种都做。

你的系统
方式一

命令行一行搞定

复制一行命令，粘进终端回车，几秒装好。不下载文件、不触发安全拦截、不需要管理员密码 —— 最省事的方式。

macOS · 终端

Spotlight 搜 "终端"（或 ⌘ + 空格 输 "Terminal"），把下面这一行粘进去回车。

curl -fsSL https://www.bnbscheduler.top/print-setup/uic-print.command | bash
Windows · PowerShell

开始菜单搜 "PowerShell"（或按 Win + X → 选"终端"），把下面这一行粘进去回车。

irm https://www.bnbscheduler.top/print-setup/uic-print.ps1 | iex
Windows 必须现在就连着校园 Wi-Fi 跑这条命令（macOS 离线也能装，到校园再打印即可）。
装好之后 · 第一次打印
  1. 连着校园 Wi-Fi、关掉代理 / VPN 才能提交（内网地址，离线会失败）
  2. 任意 App 按 ⌘ + P / Ctrl + P，打印机选 UIC打印机，点打印
  3. 提交后会自动弹账号框。万一没弹、任务停在"保留以进行认证"，就到"打印机与扫描仪"双击这台打印机，点任务右边圆圈刷新按钮手动触发。
  4. 账号框里"名称"默认是你的 Mac 用户名，一定要删掉改成你的学号 t12345678（被打回再改 UIC\t12345678）；密码是 iSpace 密码，勾"记住"。
  5. 等任务传输完成（电脑上进度条跑完），它才会出现在打印机的 release 列表里 —— 然后到图书馆任意 Toshiba e-STUDIO 前刷学生证选中它才出纸（PaperCut Find Me）
动手前，5 条必读
1
必须在校园 Wi-Fi 下
服务器地址 172.16.244.66 是内网，外网完全访问不到。
2
关掉所有代理 / VPN
Clash / Surge / V2Ray 任何一个开着，发往 172.16.x 的流量都会被拦走。
3
账号：先试单纯学号，不行再加 UIC\ 前缀
大多数情况只填 t12345678 就能过；如果反复弹"凭据无效"，改写成 UIC\t12345678（反斜杠不是斜杠）。密码就是 iSpace 密码。
4
第一次打印记得勾"记住我的凭据"
否则每次打印都要重输账号密码。
5
打完要去图书馆刷学生证才出纸
PaperCut Find Me 模式：任务先排队，你刷卡 release 后才打印。在电脑上点"打印"不会立刻吐纸。
方式二

下载脚本运行

下载一个文件双击跑。比命令行多几步（要过系统的安全拦截），但全程图形界面。

下载并安装 UIC打印机.zip
1
下载并自动解压。 点上面那个黑色"下载并安装"按钮，浏览器会下到 UIC打印机.zip，macOS 会自动解压出一个 uic-print.command 文件（在你的 下载 文件夹）。
2
双击 uic-print.command。 系统会弹一个对话框说"未打开 'uic-print.command' · Apple 无法验证..."。只有"完成"和"移到废纸篓"两个按钮，没有"打开"——这是 macOS Sequoia 新版 Gatekeeper，按 完成 关掉它。
3
放行：系统设置 → 隐私与安全性 → 仍然打开。 打开"系统设置 → 隐私与安全性"，滑到下面"安全性"那一栏，能看到一行：
"已阻止 'uic-print.command' 的使用，因为它来自身份不明的开发者"
点旁边的 仍然打开 按钮（可能要 Touch ID / 输入开机密码确认）。 放行后会再弹一次对话框，这次有 打开 按钮，点它。Terminal 自动打开并跑脚本，看到 完成! 打开 '系统设置 → 打印机与扫描仪'... 这行就成了。 脚本内容可以提前用文本编辑器查看，不要求 sudo / 管理员密码，全程只调用 macOS 自带的 lpadmin。
4
验证。 打开"系统设置 → 打印机与扫描仪"，能看到一台叫 UIC打印机 的设备就成了。
5
第一次打印（必须在校园网内发起）。
提交打印任务时必须连着 UIC 校园 Wi-Fi、关闭代理 / VPN。 打印机地址是内网 172.16.244.66，离开校园网 / 开了代理 → 数据走不到服务器 → 任务直接提交失败。
随便用任何 App 按 ⌘ + P，打印机选 UIC打印机，点打印。提交后会自动弹账号框。
万一没自动弹、任务停在"保留以进行认证"：到"打印机与扫描仪"双击这台打印机看队列，点任务右边圆圈刷新按钮手动触发。
账号框里：
  • "名称"默认填的是你的 Mac 用户名，删掉改成你的学号（如 t12345678）；被反复打回再改 UIC\t12345678
  • 密码：iSpace 密码
  • 勾选 记住此密码（钥匙串）
6
等传输完成，再去图书馆刷卡取件。 先确认电脑上的打印进度条跑完（任务传完才会进 release 队列）。然后走到任意一台 Toshiba e-STUDIO，把学生证贴在读卡器上，屏幕里选你的任务、释放即可。

方式三

纯手动添加

不下载任何文件、不跑任何脚本，全程用系统自带界面。步骤最多，但每一步你都看得到自己在改什么。

1
打开"打印机与扫描仪"。 系统设置 → 打印机与扫描仪 → 点 添加打印机、扫描仪或传真...
2
启用"高级"选项卡。 弹出的"添加打印机"窗口默认只有 默认 / IP / Windows 三个选项卡（右上角有"自定义工具栏..."按钮）。需要把"高级 (Advanced)"选项卡加出来：
  • 点右上角 自定义工具栏...（也可以 Control + 单击工具栏，选自定工具栏）
  • 在弹出的"将喜爱的项目拖入工具栏..."里找到 高级 齿轮图标
  • 把它拖到上方工具栏，点 完成
3
切到"高级"选项卡，按下面填写：
  • 类型 (Type): Windows printer via spoolss
  • 设备 (Device): 另一个设备 / Another Device
  • URL: smb://172.16.244.66/DP
  • 名称 (Name): UIC打印机（随便填，能认出来就行）
  • 位置 (Location): 留空或写 UIC 图书馆
  • 使用 (Use): 普通 PostScript 打印机
4
点"添加"。 系统会自动探测打印机选项，弹出 正在设置 "UIC 打印机..." 的对话框。如果检测到"双面打印单位"开关，保持打开；其他选项保持默认，点 好 完成。 如果想换更精确的驱动：装好 Toshiba 官方驱动后，在"打印机与扫描仪"里右键这台 → "选项与耗材" → "驱动程序"，切换到 Toshiba e-STUDIO 457 即可，不用重新添加。

关于驱动

这个配置默认用系统通用 PostScript 驱动 —— 纯文字 / PDF / 一般图文文档完全够用。如果要打非常吃驱动的东西（特殊纸张、装订排版、海报级图像），到 Toshiba 官网下载 Toshiba e-STUDIO 457 macOS / Windows 驱动 装好后，在"打印机与扫描仪"里把对应打印机的"驱动"切换过去就行，已配置的地址不用动。

打不出来怎么办

先按这个清单查一遍

macOS 提交打印后没弹账号框
新版脚本用 negotiate 认证，提交即弹（跟手动添加一样）。如果你装的是旧版脚本（任务静默失败、或停在"保留以进行认证"不弹框），重新跑一遍命令行 / 脚本即可。手动补：lpadmin -p UICPrinter -o auth-info-required=negotiate。任务停在"保留以进行认证"时也可以直接点任务右边圆圈刷新按钮触发账号框。记得把"名称"从 Mac 用户名改成学号。
ping 172.16.244.66 没反应 / 脚本第一步就失败
没连校园 Wi-Fi，或者开了代理 / VPN。先关掉所有代理软件，重连 UIC 的 Wi-Fi（不是 eduroam，确认连的是校内 SSID），再试一次。
打印机加上了，但打印出来全是乱码 / 排版错乱
通用 PostScript 驱动跟你的文档不兼容。装一份 Toshiba e-STUDIO 457 的官方驱动，在"打印机与扫描仪"里把驱动切过去。
电脑显示已提交，机器上找不到我的任务
账号填错了（PaperCut 把任务记到了别人头上），或者第一次输账号时没勾"记住"，每次提交用了不同账号。打开钥匙串访问 (Mac) / 凭据管理器 (Win)删掉 172.16.244.66 的记录，下次重新认证。
macOS 双击 .command 弹"Apple 无法验证"且只有"完成 / 移到废纸篓"
macOS Sequoia 把"右键 → 打开"那条快捷通道取消了。需要按这套流程：点 完成 → 打开"系统设置 → 隐私与安全性" → 滑到下方 安全性 区，会看到刚刚被阻止的文件 → 点 仍然打开 → 再回去双击 .command 这次会有"打开"按钮可点。
或者直接用本页"终端一行搞定"那段命令，完全绕开这个流程。
macOS 脚本跑完但"打印机与扫描仪"里没出现
完全退出"系统设置"App 再打开（macOS UI 有时不实时刷新打印机列表）。或者打开"终端"运行 lpstat -p，能看到 UICPrinter 就说明已经加上了，只是 UI 显示有延迟。
Windows 报"找不到网络路径 / 0x80070035"
系统禁用了 SMB 客户端。控制面板 → 程序 → 启用或关闭 Windows 功能，勾上 SMB 1.0/CIFS File Sharing Support（仅勾"客户端"子项就够，不要勾服务器）。重启后再跑脚本。
提示"凭据无效"反复重输
你的电脑没有自动识别 UIC 域。把账号从 t12345678 改成 UIC\t12345678 再试。`UIC\` 是 Active Directory 的域名前缀，反斜杠不是斜杠。
以上都试过还不行
到图书馆服务台问 IT，或者来找我。本工具只是把官方配置打包成一键安装，底层流程跟人工添加是完全一样的。

这个页面只做两件事：① 给你一个配置文件下载；② 告诉你怎么用。不收集你的 UIC 账号、密码、学号、任何登录凭据。配置文件里也不包含任何账号信息，账号是你的电脑直接跟 PaperCut 通信时输入的，全程经过你的本地系统，跟这个网站没有任何关联。打印计费照常按你的 PaperCut 账户记。
