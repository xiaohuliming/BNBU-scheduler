校园打印一键配置

自动把 UIC 图书馆的共享打印机 (172.16.244.66 / DP, Toshiba e-STUDIO 457) 加进你的电脑。

检测到你的系统

macOS

下载并安装 UIC图书馆打印.mobileconfig
下载 UIC图书馆打印.bat

这个文件给另一个系统用。检测错了？直接点这个就行。

动手前，5 条必读
1
必须在校园 Wi-Fi 下
服务器地址 172.16.244.66 是内网，外网完全访问不到。
2
关掉所有代理 / VPN
Clash / Surge / V2Ray 任何一个开着，发往 172.16.x 的流量都会被拦走。
3
账号：先试单纯学号，不行再加 UIC\ 前缀
大多数情况只填 t330025032 就能过；如果反复弹"凭据无效"，改写成 UIC\t330025032（反斜杠不是斜杠）。密码就是 iSpace 密码。
4
第一次打印记得勾"记住我的凭据"
否则每次打印都要重输账号密码。
5
打完要去图书馆刷学生证才出纸
PaperCut Find Me 模式：任务先排队，你刷卡 release 后才打印。在电脑上点"打印"不会立刻吐纸。
安装步骤

跟着做就好

1
下载配置文件。 点上面那个黑色"下载并安装"按钮，浏览器会下到一个 UIC图书馆打印.mobileconfig。
2
双击打开它。 Safari 会提示"该网站正在尝试下载配置描述文件"，点允许。系统会跳出通知说"已下载该描述文件，请在系统设置中进行检查"。 [ 占位图：双击后的系统通知 ]
3
打开"系统设置 → 通用 → 设备管理"（旧版 macOS 是"系统偏好设置 → 描述文件"）。在"已下载"里找到 UIC 图书馆打印机配置，点 安装，输入 Mac 开机密码确认。 [ 占位图：设备管理里的描述文件 ]
4
验证。 打开"系统设置 → 打印机与扫描仪"，能看到一台叫 UIC 图书馆打印 的设备就成了。
5
第一次打印。 随便用任何 App 按 ⌘ + P，打印机选 UIC 图书馆打印，点打印，弹窗里：
  • 账号：先输你的学号（如 t330025032）；如果被反复打回，改成 UIC\t330025032
  • 密码：iSpace 密码
  • 勾选 记住此密码（钥匙串）
提交后任务进入 PaperCut 队列。
6
去图书馆刷卡取件。 走到任意一台 Toshiba e-STUDIO，把学生证贴在读卡器上，屏幕里选你的任务、释放即可。
1
下载脚本。 点上面那个黑色"下载并安装"按钮，浏览器会下到一个 UIC图书馆打印.bat。

右键 → 以管理员身份运行。 Windows Defender 可能弹"是否运行"，点 更多信息 → 仍要运行（脚本内容你可以提前用记事本打开看，只有两条命令：测试网络 + 加打印机）。 [ 占位图：右键菜单与 Defender 提示 ]

不想下载我的文件？

纯手动添加

如果你对来路不明的脚本 / 描述文件不放心，下面这套步骤完全用系统自带界面完成，每一步都看得到自己在改什么。结果跟自动安装完全一样。

1
打开"打印机与扫描仪"。 系统设置 → 打印机与扫描仪 → 点 添加打印机、扫描仪或传真... [ 占位图：打印机与扫描仪界面 ]
2
启用"高级"选项卡。 弹出的"添加"窗口默认只有 IP、Windows、Default 几个选项。需要把"高级 (Advanced)"选项卡加出来：
  • Control + 单击窗口顶部工具栏
  • 选 自定工具栏...
  • 把"高级"齿轮图标拖到工具栏，点完成
3
切到"高级"选项卡，按下面填写：
  • 类型 (Type): Windows printer via spoolss
  • 设备 (Device): Another Device
  • URL: smb://172.16.244.66/DP
  • 名称 (Name): UIC 图书馆打印（可以自己改）
  • 位置 (Location): UIC 图书馆（可选）
  • 使用 (Use): Generic PostScript Printer
[ 占位图：高级选项卡填写后 ]
4
点"添加"。 如果系统提示选择驱动，挑 Generic PostScript Printer 就够用了。装了 Toshiba 官方驱动的话，能在列表里看到 Toshiba e-STUDIO 457，选它体验更好。
5
第一次打印。 任意 App 按 ⌘ + P，打印机选刚才那台，提交后弹账号窗口：
  • 账号：UIC\你的学号
  • 密码：iSpace 密码
  • 勾选 记住此密码（钥匙串）
6
去图书馆刷卡取件。 到任意 Toshiba e-STUDIO 前刷学生证 release 任务才会出纸。
1
按 Win + R 打开"运行"。 在输入框输入下面这一行，回车：
\\172.16.244.66\DP
（路径分隔符是反斜杠 \，不是 /。） [ 占位图：运行窗口输入 \\IP\DP ]
2
输入凭据。 Windows 弹窗要账号密码，按这个填：
  • 用户名：先输学号（如 t330025032）；不行再带前缀 UIC\t330025032
  • 密码：iSpace 密码
  • 勾选 记住我的凭据
3
系统会自动安装这台共享打印机。 如果弹"是否信任来自此共享的打印机驱动"，点 安装驱动程序。等几秒钟即可。
4
验证。 开始菜单搜 打印机 → 打开"打印机和扫描仪"，应该能看到 172.16.244.66 上的 DP。
5
方法 A 失败的话，走传统添加流程：
  • 设置 → 蓝牙和其他设备 → 打印机和扫描仪
  • 点 添加设备，等列表加载完几秒
  • 点 "我需要的打印机不在列表中"
  • 选 "按名称选择共享打印机"
  • 输入 \\172.16.244.66\DP，下一步
  • 同样会弹凭据窗口，按上面填
6
去图书馆刷卡取件。 到任意 Toshiba e-STUDIO 前刷学生证 release 任务才会出纸。
关于驱动

这个配置默认用系统通用 PostScript 驱动 —— 纯文字 / PDF / 一般图文文档完全够用。如果要打非常吃驱动的东西（特殊纸张、装订排版、海报级图像），到 Toshiba 官网下载 Toshiba e-STUDIO 457 macOS / Windows 驱动 装好后，在"打印机与扫描仪"里把对应打印机的"驱动"切换过去就行，已配置的地址不用动。

打不出来怎么办

先按这个清单查一遍

ping 172.16.244.66 没反应 / 脚本第一步就失败
没连校园 Wi-Fi，或者开了代理 / VPN。先关掉所有代理软件，重连 UIC 的 Wi-Fi（不是 eduroam，确认连的是校内 SSID），再试一次。
打印机加上了，但打印出来全是乱码 / 排版错乱
通用 PostScript 驱动跟你的文档不兼容。装一份 Toshiba e-STUDIO 457 的官方驱动，在"打印机与扫描仪"里把驱动切过去。
电脑显示已提交，机器上找不到我的任务
账号填错了（PaperCut 把任务记到了别人头上），或者第一次输账号时没勾"记住"，每次提交用了不同账号。打开钥匙串访问 (Mac) / 凭据管理器 (Win)删掉 172.16.244.66 的记录，下次重新认证。
macOS 双击 .mobileconfig 没反应 / 报"该文件不是有效的配置描述文件"
浏览器把文件后缀改错了（变成 .mobileconfig.txt）。在 Finder 里手动改回 .mobileconfig 再双击；或者改用 Safari 重新下载。
Windows 报"找不到网络路径 / 0x80070035"
系统禁用了 SMB 客户端。控制面板 → 程序 → 启用或关闭 Windows 功能，勾上 SMB 1.0/CIFS File Sharing Support（仅勾"客户端"子项就够，不要勾服务器）。重启后再跑脚本。
提示"凭据无效"反复重输
你的电脑没有自动识别 UIC 域。把账号从 t330025032 改成 UIC\t330025032 再试。`UIC\` 是 Active Directory 的域名前缀，反斜杠不是斜杠。
以上都试过还不行
到图书馆服务台问 IT，或者来找我。本工具只是把官方配置打包成一键安装，底层流程跟人工添加是完全一样的。
