校园打印一键配置

网页打印可在校园 Wi-Fi、手机热点和校外网络提交。下面的脚本会检测连接，学校队列可达时配置系统打印机，否则打开网页打印。

MAXCOURSE / REMOTE PRINTING

先选文件，打印时再填学校账号。

网页提交后由 MAXCOURSE 送到学校打印队列，提交成功后到图书馆刷卡取件，不需要安装打印机驱动。

打开网页打印 ↗

正在检查网页打印服务…

每个文件最多 50 MB、300 页，可选黑白、彩色、单双面和 1 至 100 份。

系统打印机与网页打印如何选择？

想继续在 App 里按 ⌘P 或 Ctrl+P，电脑需要能够直连学校打印队列。学生 Wi-Fi 与打印网络可能隔离，插入网线后也要以 TCP 445 检查结果为准。

网页打印只在网页里提交，不会添加为系统打印机。脚本检测到队列不可达时，直接打开上方网页入口。

电脑直连配置 · 三种方式任选其一

队列可达时，命令行和下载脚本配置同一台系统打印机。纯手动步骤仅用于学校队列可达的网络。

你的系统
方式一

命令行一行搞定

复制一行命令，在终端回车。脚本先检查学校队列；可达时配置系统打印机，不可达时打开网页打印。Windows 安装学校驱动时可能需要管理员确认。

macOS · 终端

Spotlight 搜 "终端"（或 ⌘ + 空格 输 "Terminal"），把下面这一行粘进去回车。

curl -fsSL 'https://www.bnbscheduler.top/print-setup/uic-print.command?v=20261001' | bash
Windows · PowerShell

开始菜单搜 "PowerShell"（或按 Win + X → 选"终端"），把下面这一行粘进去回车。

irm 'https://www.bnbscheduler.top/print-setup/uic-print.ps1?v=20261001' | iex
先检查队列，避免装好却打不出来。 校园 Wi-Fi、网线和 VPN 是否能直连，均以脚本的 TCP 445 检查为准；不可达时使用网页打印。
装好之后 · 第一次打印
  1. 下列步骤适用于脚本已配置系统打印机的情况。 如果脚本打开的是网页，按网页上传、预览、填写账号并提交即可。
  2. 任意 App 按 ⌘ + P / Ctrl + P，Mac 选择 UIC打印机，Windows 选择学校 DP 队列，再点打印
  3. 系统需要认证时输入本人学校账号。Mac 任务如果停在"保留以进行认证"，就到"打印机与扫描仪"双击这台打印机，点任务右边圆圈刷新按钮手动触发。
  4. 账号框里"名称"默认是你的 Mac 用户名，一定要删掉改成你的学号 t12345678（被打回再改 UIC\t12345678）；密码是 iSpace 密码，勾"记住"。
  5. 等任务传输完成（电脑上进度条跑完），它才会出现在打印机的 release 列表里 —— 然后到图书馆支持学校刷卡队列的打印机 前刷学生证选中它才出纸（PaperCut Find Me）
电脑直连时的 5 条须知
1
系统打印机需要队列可达
学校队列是内网地址。普通 Wi-Fi 和校外网络可直接用网页打印。
2
网页打印保留正常上网连接
网页打印只需访问本站。电脑直连时，检查内网路由和 TCP 445，无需一律关闭所有代理。
3
账号格式：Mac 和 Windows 不一样
macOS：直接填学号 t12345678 就行（系统自动识别 UIC 域）。
Windows：必须带前缀 UIC\t12345678（Windows 不会自动识别域，不加直接被拒）。反斜杠不是斜杠。密码都是 iSpace 密码。
4
第一次打印记得勾"记住我的凭据"
否则每次打印都要重输账号密码。
5
打完要去图书馆刷学生证才出纸
PaperCut Find Me 模式：任务先排队，你刷卡 release 后才打印。在电脑上点"打印"不会立刻吐纸。
方式二

下载脚本运行

下载后运行，脚本会根据连接结果配置系统打印机或打开网页。下面的系统配置步骤只适用于脚本提示队列可达的情况。

下载配置脚本 UIC打印机.zip
1
下载并自动解压。 点上面那个黑色"下载配置脚本"按钮，浏览器会下到 UIC打印机.zip，macOS 会自动解压出一个 uic-print.command 文件（在你的 下载 文件夹）。
2
双击 uic-print.command。 系统会弹一个对话框说"未打开 'uic-print.command' · Apple 无法验证..."。只有"完成"和"移到废纸篓"两个按钮，没有"打开"——这是 macOS Sequoia 新版 Gatekeeper，按 完成 关掉它。
3
放行：系统设置 → 隐私与安全性 → 仍然打开。 打开"系统设置 → 隐私与安全性"，滑到下面"安全性"那一栏，能看到一行：
"已阻止 'uic-print.command' 的使用，因为它来自身份不明的开发者"
点旁边的 仍然打开 按钮（可能要 Touch ID / 输入开机密码确认）。 放行后会再弹一次对话框，这次有 打开 按钮，点它。Terminal 自动打开并跑脚本，按脚本结果继续：显示“已配置 UIC打印机”就用系统打印窗口；打开网页就直接上传文件。 脚本内容可以提前用文本编辑器查看，不要求 sudo / 管理员密码，仅使用 macOS 自带的连接检查、打印机配置和浏览器打开功能。
4
验证。 打开"系统设置 → 打印机与扫描仪"，能看到一台叫 UIC打印机 的设备就成了。
5
系统打印机首次提交，需要学校队列可达。
提交时需要可以访问学校队列的网络。 学生 Wi-Fi 可能隔离打印网络。无法访问队列时，请使用 网页打印，无需重新安装打印机。
用 App 按 ⌘ + P，选择 UIC打印机，再点打印。提交后会自动弹账号框。
万一没自动弹、任务停在"保留以进行认证"：到"打印机与扫描仪"双击这台打印机看队列，点任务右边圆圈刷新按钮手动触发。
账号框里：
  • "名称"默认填的是你的 Mac 用户名，删掉改成你的学号（如 t12345678）；被反复打回再改 UIC\t12345678
  • 密码：iSpace 密码
  • 勾选 记住此密码（钥匙串）
6
等传输完成，再去图书馆刷卡取件。 先确认电脑上的打印进度条跑完（任务传完才会进 release 队列）。然后走到任意一台 Toshiba e-STUDIO，把学生证贴在读卡器上，屏幕里选你的任务、释放即可。
1
下载脚本。 点上面那个黑色"下载配置脚本"按钮，浏览器会下到一个 UIC打印机.bat。
2
双击运行。 如果 Windows 安装学校驱动时要求管理员权限，再按系统提示确认。 Windows Defender 可能弹"是否运行"，点 更多信息 → 仍要运行（脚本内容你可以提前用记事本打开看，只有两条命令：测试网络 + 加打印机）。
3
等脚本跑完。 正常情况下会看到两个 OK，最后提示"完成"，按任意键关窗。
4
验证。 开始菜单搜 打印机 → 打开"打印机和扫描仪"，能看到 172.16.244.66 上的 DP 就成了。
5
系统打印机首次提交，需要学校队列可达。
提交时需要可以访问学校队列的网络。 学生 Wi-Fi 可能隔离打印网络。无法访问队列时，请使用 网页打印，无需重新安装打印机。
任意 App 按 Ctrl + P，打印机选刚才那台，点打印，Windows 会弹凭据窗口：
  • 用户名必须带 UIC\ 前缀：UIC\t12345678（Windows 不会自动识别域，不加前缀直接被拒）
  • 密码：iSpace 密码
  • 勾选 记住我的凭据
6
等传输完成，再去图书馆刷卡取件。 先等打印进度条跑完（任务传完才进 release 队列），再到支持学校刷卡队列的打印机 前刷学生证 release 你的任务。
方式三

纯手动添加

不下载任何文件、不跑任何脚本，全程用系统自带界面。步骤最多，但每一步你都看得到自己在改什么。

1
打开"打印机与扫描仪"。 系统设置 → 打印机与扫描仪 → 点 添加打印机、扫描仪或传真...
2
启用"高级"选项卡。 弹出的"添加打印机"窗口默认只有 默认 / IP / Windows 三个选项卡（右上角有"自定义工具栏..."按钮）。需要把"高级 (Advanced)"选项卡加出来：
  • 点右上角 自定义工具栏...（也可以 Control + 单击工具栏，选自定工具栏）
  • 在弹出的"将喜爱的项目拖入工具栏..."里找到 高级 齿轮图标
  • 把它拖到上方工具栏，点 完成
3
切到"高级"选项卡，按下面填写：
  • 类型 (Type): Windows printer via spoolss
  • 设备 (Device): 另一个设备 / Another Device
  • URL: smb://172.16.244.66/DP
  • 名称 (Name): UIC打印机（随便填，能认出来就行）
  • 位置 (Location): 留空或写 UIC 图书馆
  • 使用 (Use): 普通 PostScript 打印机
4
点"添加"。 系统会自动探测打印机选项，弹出 正在设置 "UIC 打印机..." 的对话框。如果检测到"双面打印单位"开关，保持打开；其他选项保持默认，点 好 完成。 如果想换更精确的驱动：装好 Toshiba 官方驱动后，在"打印机与扫描仪"里右键这台 → "选项与耗材" → "驱动程序"，切换到 Toshiba e-STUDIO 457 即可，不用重新添加。
5
系统打印机首次提交，需要学校队列可达。
提交时需要可以访问学校队列的网络。 学生 Wi-Fi 可能隔离打印网络。无法访问队列时，请使用 网页打印，无需重新安装打印机。
任意 App 按 ⌘ + P，打印机选刚才那台，点打印。提交后会自动弹账号框。
万一没自动弹、任务停在"保留以进行认证"：到"打印机与扫描仪"双击这台打印机，点任务右边圆圈刷新按钮手动触发。
账号框里：
  • "名称"默认是你的 Mac 用户名，删掉改成学号（如 t12345678）；不行再加前缀 UIC\t12345678
  • 密码：iSpace 密码
  • 勾选 记住此密码（钥匙串）
6
等传输完成，再去图书馆刷卡取件。 先等打印进度条跑完（任务传完才进 release 队列），再到支持学校刷卡队列的打印机 前刷学生证 release 任务才会出纸。
1
按 Win + R 打开"运行"（先确保在校园网内）。
手动配置前，先确认学校队列 TCP 445 可以连接。 172.16.244.66 是内网地址，出了校园 / 走代理就连不上。
在输入框输入下面这一行，回车：

（路径分隔符是反斜杠 \，不是 /。）
2
输入凭据。 Windows 弹窗要账号密码，按这个填：

  • 密码：iSpace 密码
  • 勾选 记住我的凭据
3
系统会自动安装这台共享打印机。 如果弹"是否信任来自此共享的打印机驱动"，点 安装驱动程序。等几秒钟即可。

5
方法 A 失败的话，走传统添加流程：
  • 设置 → 蓝牙和其他设备 → 打印机和扫描仪
  • 点 添加设备，等列表加载完几秒
  • 点 "我需要的打印机不在列表中"
  • 选 "按名称选择共享打印机"
  • 输入 \\172.16.244.66\DP，下一步
  • 同样会弹凭据窗口，按上面填

等传输完成，再去图书馆刷卡取件。 先等打印进度条跑完（任务传完才进 release 队列），再到支持学校刷卡队列的打印机 前刷学生证 release 任务才会出纸。
关于驱动

Mac 直连使用系统通用 PostScript 驱动，Windows 使用学校共享队列的驱动。网页打印不需要电脑安装学校打印机驱动。

打不出来怎么办

按当前提交方式检查

脚本打开了网页，系统里没有新增打印机
这是当前网络无法访问学校队列时的结果。在网页选择文件、确认预览、输入本人学校账号并提交。校园 Wi-Fi 或校外网络不需要安装直连打印机。
希望继续在 App 里按 ⌘P 或 Ctrl+P
先使用能够访问学校队列的网络，再运行脚本。Mac 显示 UIC打印机，Windows 显示学校 DP 共享队列。
系统打印机任务停在等待认证
确认学校队列可达，再在系统任务窗口重新认证。Mac 用本人学校账号，Windows 可用 UIC\学号。仅处理这台打印机的任务；也可以改用网页打印。
网页提示打印服务未连接
可以先选择 PDF 生成本地预览，服务恢复后再提交。Word 等文件需要服务在线才能转换。不要通过重复新建任务来判断是否恢复。
任务显示结果待确认，或打印机找不到任务
先查看网页任务记录和本人刷卡列表，核对账号与任务时间。结果待确认时先查询，避免重复提交。网站回执确认的是学校队列接收，实际取件需本人刷卡。
Windows 能看到学校共享，但无法安装驱动
按 Windows 的错误提示确认权限和学校提供的签名驱动，或直接使用网页打印。网页提交不需要电脑安装学校驱动。
版式或内容不符合预期
提交前检查预览。Word 等文件转换后字体和分页可能变化，必要时先从原 App 导出 PDF，再用网页打印。
隐私说明

安装脚本不收集或缓存学校账号密码。网页提交时通过 HTTPS 填写本人学校账号与密码，校园打印服务不把文档和密码写入任务数据库，临时文件处理后清理。
