隐私与安全说明

这是由学生独立维护的校园工具项目，并非学校官方产品。项目没有获得学校官方认证，也没有学校向本项目开放的校园系统接口。

非必要，不要向第三方提供自己的学号和密码，包括本项目。

即使不登录 iSpace，也可以使用课程浏览、排课优化、空教室查询、校园资料浏览等大部分服务。是否使用校园账号相关功能，由你自行决定。

开源可查，不等于没有风险

主项目公开仓库：github.com/xiaohuliming/BNBU-scheduler。登录、学校邮箱读取、摘要请求、缓存和解绑处理的相关代码可在仓库中检查，也欢迎通过 GitHub Issues 提出问题。

本次更新对密码持久化路径、邮箱请求边界、账号数据隔离、解绑后的任务撤销、静态文件保护和页面输出进行了范围有限的代码自查与自动化回归检查。查看本次检查范围和验证记录。

这些工作由开发者借助自动化工具完成，不是第三方独立安全审计。目前没有可公开提供的独立审计报告或学校安全认证。开源代码不能单独证明线上部署始终与仓库一致，也不能保证绝对安全。欢迎有能力的同学自行检查或独立审计。

账号与密码怎样处理

  • 手动输入模式不会持久保存校园密码。你在 iSpace 登录、绑定或手动同步时输入的密码，会经本项目服务器通过 HTTPS 交给学校系统，处理期间短暂存在于内存，完成后丢弃。不会因为一次登录就自动将密码保存进数据库。
  • 如果你主动开启 DDL 自动同步，密码会加密保存在服务器。后台管理界面不显示明文密码，也没有向管理员展示明文的接口。但服务器持有解密密钥，执行自动同步或恢复邮箱会话时仍会解密使用。因此，加密不等于服务器绝对无法获知密码，也不能保证服务器被入侵后密码不会泄露。
  • 介意服务器保存加密密码的话，请保持自动同步关闭，每次按需要手动填写。关闭自动同步会清除在线业务库中的密码密文；在设置中删除 iSpace 绑定，也会一并清除该密文和相关校园数据。
  • 绑定功能会保存校园账号标识，用来关联本站账号和数据。不保存密码与不保存账号标识是两回事。你可以在设置中解除绑定。
  • 邮箱临时登录状态只保存在服务器内存，最长八小时，学校也可能提前使其失效。退出、解绑或重启会清除该会话。没有保存密码时，会话失效后需要再次手动输入；已主动开启加密保存时，服务器可以使用保存的密码重新建立会话。
  • 本站独立账号的密码只保存单向校验哈希，不保存原始密码。请不要将校园密码重复用作本站密码。

可选加密保存功能在历史版本中已经存在，本次保留。相关实现与历史变更均可在 GitHub 检查。因此，本站不作“从未保存过校园密码”或“服务器无法解密”的承诺。

邮件摘要使用哪些数据

iSpace 登录成功后，服务器会通过 MIS 的正常登录跳转连接校园邮箱。此过程使用网页会话，不是学校提供给本项目的官方 API。每次进入已登录的首页，都会尝试检查最近七天的收件箱邮件，包含已读和未读，并在后台生成简短摘要。同一时间已有更新任务时会复用该任务，状态轮询不会重复触发。

读取采用邮箱预览方式，保留邮件的已读、未读状态，不发送或删除邮件，不下载附件，也不读取图片与二维码的内容。为限制单次处理规模，最多处理一百五十封近期邮件，较长正文可能截断；覆盖不完整时会标注。请以学校邮件原文为准。

所选范围内的发件人、主题、时间和正文文字会提交给 OmniChat 服务及其配置的模型提供方处理。邮件正文可能本身包含个人信息，使用前请考虑这一点。校园密码、邮箱会话标识不会作为模型输入字段发送。当前费用由项目服务端承担，不扣用户个人的 OmniChat 积分。

原始邮件正文不写入本项目数据库。简短摘要、选中来源的主题与时间、覆盖范围会加密缓存，并按本站账号隔离。超过一天的摘要不会继续展示。主项目公开代码能够检查这部分处理，但 OmniChat 服务及上游模型服务不在本仓库的完整开源和审计范围内。我们不对第三方服务的数据留存方式作未经核实的保证。

怎样删除已添加的 iSpace 账号

在本站打开设置 → iSpace Linked → 删除已添加的 iSpace 账号。确认后，会解除校园账号关联、撤销相关进行中的后台任务，并清除在线业务库中的校园密码密文、临时邮箱会话、邮件摘要和从 iSpace 导入的待办及其提醒记录。已发出的网络请求无法撤回，但解绑后不会继续请求后续邮件或写回旧任务结果。

解绑不会删除学校账号或学校邮件，也不会注销你的本站账号、删除手动创建的待办。本站独立账号标识可能仍包含最初使用的学号。若希望一并删除本站账号数据，请使用设置中的账号注销。主动再次使用 iSpace 登录或绑定，会重新建立关联。

解绑后，在线业务库立即按上述范围清除。历史数据库备份可能保留解绑前的账号数据和密码密文，不会自动用于恢复绑定或重新登录，会按维护流程处理；本说明不承诺即时抹除所有历史备份。不要把解绑理解为修改了学校密码或撤销了学校所有设备上的登录。

其他必要数据与使用建议

为提供账号、待办、评价、限流和服务维护功能，项目还会处理相应账号标识、你主动保存的数据和必要访问日志。HTTP 访问日志可能包含 IP、时间、路径及状态码。不要在公开评论、问题反馈或聊天中粘贴密码、邮箱登录链接、Cookie、验证码或其他敏感信息。

如不确定学校系统入口，请以学校官网或 ITSC 发布的入口为准。开发者不会通过微信或 GitHub 向你索取校园密码。不要因为项目公开源码或认识开发者，就放松对凭据的保护。
